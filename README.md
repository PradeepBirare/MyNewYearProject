# 🏨 New Year Hotel Booking & Sales Dashboard – Django

A Django-based web application developed to help users explore hotels and find suitable locations for celebrating New Year. The project provides hotel information, location/map-based access, and a sales dashboard for analyzing hotel sales performance for the selected day.

---

## 📌 Project Overview

This project is designed around the idea of helping people discover hotels and suitable places to celebrate New Year.

The application contains:

- 🏨 Hotel details and information
- 📍 Hotel location and map-based access
- 🎉 New Year celebration hotel discovery
- 📊 Hotel sales dashboard
- 📈 Daily hotel sales analysis
- 🗄️ SQLite database integration
- 🌐 Django-based web application

The project combines a **hotel information platform** with a **sales analytics dashboard**, allowing users to explore hotels while providing a view of hotel sales performance for a particular day.

⚙️ Installation & Setup
1. Clone the Repository
git clone <your-repository-url>

Move into the project directory:
cd <project-folder>

2. Create a Virtual Environment
Create a Python virtual environment:
python -m venv venv

Activate it on Windows:
venv\Scripts\activate

On macOS/Linux:
source venv/bin/activate

3. Install Dependencies
Install Django:
pip install django

If the project contains a requirements.txt file:
pip install -r requirements.txt

4. Run Database Migrations
python manage.py makemigrations
python manage.py migrate

5. Start the Django Development Server
python manage.py runserver

Open the application in your browser:
http://127.0.0.1:8000/
